# ProbablyWorks web

Готовая статическая сборка web-клиента ProbablyWorks.

## Размещение

Содержимое архива кладётся в корень сайта. Точка входа — `index.html`.

Сервер ProbablyWorks запускается отдельно; на экране подключения укажите его
адрес и токен.

URL используют hash-навигацию (`/#/a/<profileId>/chats`), поэтому
специальная настройка rewrite на статическом хостинге не нужна.

## Сервер

Запустите сервер ProbablyWorks и разрешите CORS для адреса web-клиента:

```bash
pw_server --port 7787 \
  --allow-origin https://web.example.com
```

Если web-клиент открывается по HTTPS, сервер тоже должен быть доступен по
HTTPS: браузер блокирует запросы к HTTP из защищённой страницы. Для внешнего
доступа используйте SSH-туннель, VPN или TLS reverse proxy.

Токен API печатается при запуске с `--print-token` или задаётся через
`PROBABLY_WORKS_API_TOKEN`.
