# ProbablyWorks — Brand & Visual Identity Specification

**Версия:** 0.1
**Статус:** Initial visual specification

## 1. Концепция бренда

**Название:** ProbablyWorks

**Основная идея:** неопределённость, исследование и решение задач через взаимодействие с ИИ.

Визуальная метафора бренда — клубок пряжи. Он символизирует сложную задачу, состоящую из множества взаимосвязанных элементов. Кошка, играющая с клубком, олицетворяет любопытство, исследование и способность находить решения.

Бренд должен восприниматься как:
- Дружелюбный, но не детский.
- Технологичный, но не холодный.
- Игривый, но не несерьёзный.
- Простой и легко узнаваемый.

Не использовать типичные визуальные клише ИИ: роботы, мозги, нейронные сети, микросхемы, терминалы, шестерёнки и галочки.

## 2. Основные элементы айдентики

### 2.1. Клубок пряжи (основной символ)

Клубок — самостоятельный элемент логотипа и основная иконка приложения.

Характеристики:
- Форма близка к круглой.
- Состоит из переплетающихся нитей.
- Нити образуют узнаваемую структуру клубка, а не абстрактную запутанную линию.
- Несколько свободных концов нитей допустимы.
- Переплетения должны быть визуально понятны.
- Символ должен хорошо читаться в небольшом размере.
- Без дополнительных символов внутри клубка.

Клубок должен оставаться узнаваемым без присутствия кошки.

### 2.2. Кошка (маскот)

Кошка — отдельный персонаж, который может использоваться в иллюстрациях, анимациях, интерфейсе и маркетинговых материалах.

Характеристики:
- Простая стилизованная кошка.
- Белое или очень светлое тело.
- Тёмно-синий контур.
- Минималистичные черты морды.
- Выразительные, но простые глаза.
- Мягкие округлые формы.
- Дружелюбная и любопытная поза.

Основное действие — взаимодействие с клубком пряжи: игра, исследование, попытка распутать нити.

Кошка не должна выглядеть как реалистичное животное или сложная мультяшная иллюстрация.

**Важно:** внешний вид кошки должен оставаться неизменным во всех изображениях. Нельзя произвольно менять форму головы, пропорции тела, форму ушей, глаз, хвоста и толщину контура.

### 2.3. Типографика

Название: `ProbablyWorks`

Предпочтительный шрифт: **Nunito ExtraBold (800)**.

Характеристики:
- Округлые геометрические формы.
- Хорошая читаемость.
- Достаточно плотное начертание.
- Без засечек.
- Без декоративных элементов.

Рекомендуемое цветовое разделение:
- `Probably` — тёмно-синий.
- `Works` — синий или сине-фиолетовый.

Название должно набираться настоящим шрифтом, а не генерироваться нейросетью внутри изображения.

После утверждения логотипа текст необходимо преобразовать в векторные контуры для финальной версии.

## 4. Стиль иллюстраций

Основной стиль — clean modern flat vector.

Характеристики:
- Ровные толстые контуры.
- Скруглённые окончания линий.
- Скруглённые соединения линий.
- Минимальное количество деталей.
- Плоские заливки.
- Допускаются небольшие мягкие цветовые переходы.
- Минимальные тени, только если они помогают разделять объекты.

Все элементы должны выглядеть так, будто нарисованы одним автором в рамках одной дизайн-системы.

Не использовать:
- Фотореализм.
- 3D-рендеринг.
- Сложные градиенты.
- Тонкие случайные линии.
- Избыточные декоративные детали.
- Разные художественные стили в одной композиции.

## 5. Правила композиции

Необходимо поддерживать три самостоятельных типа графики:

**A. Icon**
- Только клубок.
- Квадратная композиция.
- Прозрачный фон.
- Без текста и дополнительных объектов.

**B. Mascot**
- Только кошка.
- Прозрачный фон.
- Без клубка и дополнительных объектов.
- Сохраняет утверждённый дизайн персонажа.

**C. Full Logo**
- Кошка взаимодействует с клубком.
- Название ProbablyWorks располагается отдельно от иллюстрации.
- Композиция горизонтальная или вертикальная.
- Элементы не перекрывают друг друга случайным образом.

## 6. Правила генерации изображений

При создании новых изображений:

1. Использовать утверждённое изображение клубка как reference image.
2. Использовать утверждённое изображение кошки как reference image.
3. Не менять их пропорции и характерные особенности.
4. Использовать только утверждённую палитру.
5. Сохранять толщину контуров.
6. Не добавлять новые элементы дизайна без необходимости.
7. Генерировать объекты отдельно, если требуется высокая точность.
8. Финальную композицию собирать из утверждённых элементов.

### Negative prompt

Photorealistic, 3D, realistic fur, detailed textures, thin outlines, inconsistent line weight, random colors, robotic elements, computers, laptops, terminals, checkmarks, shields, gears, neural networks, excessive gradients, complex backgrounds, typography inside illustrations.

## 8. Критерии проверки результата

Каждая новая иллюстрация должна соответствовать следующим условиям:

- Клубок узнаваем и соответствует эталону.
- Кошка сохраняет свою внешность.
- Цвета соответствуют палитре.
- Толщина линий соответствует стилю.
- Композиция не содержит случайных элементов.
- Изображение хорошо читается в небольшом размере.
- Элементы можно использовать совместно с другими материалами бренда.

Если результат не соответствует этим требованиям, он не считается утверждённым элементом фирменного стиля.
